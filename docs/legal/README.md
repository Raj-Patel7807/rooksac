# Legal

RookSac has no selected license and is not represented as open source. The project must not publish a `LICENSE`, copyright notice, SPDX source header, or `NOTICE` file until the owner confirms the necessary legal decisions.

- [Licensing and notices](LICENSING_AND_NOTICES.md) records the current inventory, permissive-license trade-offs, owner decision checklist, SBOM plan, and future asset review process.
- [Third-party notices](THIRD_PARTY_NOTICES.md) records the absence of current distributed third-party components and the information required before any are added.

These documents are engineering records, not legal advice. See the root [security policy](../../SECURITY.md) and [support guidance](../../SUPPORT.md) for the policies currently present.
