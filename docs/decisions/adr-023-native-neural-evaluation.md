# ADR-023 — Native neural evaluation and policy-guided move ranking

- **Status:** Accepted
- **Context / problem:** While deep neural models are trained offline in Python (`research/nn/`), real-time chess engine search requires sub-millisecond leaf evaluations without process switches or Python runtime overhead. We need native C++ neural inference acting as a pluggable leaf evaluator and legal-move ranking guide within Alpha-Beta search.
- **Options considered:**
  1. Spawning Python subprocesses or embedding the CPython runtime inside the engine leaf evaluator.
  2. Linking heavy external dynamic dependencies (e.g. libtorch/ONNX Runtime C++ shared libraries).
  3. Standalone, zero-allocation native C++ neural inference module (`NeuralEvaluator`) with 18-plane feature extraction, inverse-sigmoid value calibration to centipawns, and policy ranking strictly over legal moves.
- **Decision:** Implement option 3:
  - **Native Feature Encoding:** `encodePosition` maps `Position` to an $18 \times 8 \times 8$ planar float array without dynamic allocation.
  - **Value Calibration:** Converts neural prediction $v \in [-1, 1]$ from White's perspective into engine centipawns using calibrated inverse sigmoid:
    $$\text{score}_{\text{cp}} = -\frac{400}{K} \cdot \log_{10}\left(\frac{1 - v}{1 + v}\right)$$
    evaluated with correct side-to-move sign handling.
  - **Policy Move Ranking:** `orderMovesByPolicy` maps $64 \times 64$ action logits exclusively to legal moves generated by `rooksac_core`, guaranteeing that neural policy can never propose or execute illegal moves.
  - **Zero Python Runtime Dependency:** Native execution is completely self-contained in `rooksac_core` with zero per-node heap allocation.
- **Consequences:**
  - Fast, memory-bounded neural leaf evaluation integrated smoothly into Alpha-Beta iterative deepening.
  - Strict preservation of chess rules and legal move invariants.
  - Deterministic evaluation and transparent fallback to classical evaluation if a model fails to load.
