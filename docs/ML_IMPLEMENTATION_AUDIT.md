## 1. Executive Summary

This audit examines the state of machine learning training, export, native C++ neural inference, search integration, UCI protocol options, FastAPI orchestration, React frontend integration, containerization, and documentation claims in the RookSac repository.

### Key Audit Findings
1. **Model Training & Dataset (RESOLVED)**: `tools/pgn_extract.py` provides streaming PGN ingestion with python-chess legal move replay, content-hash deduplication, quality filters, whole-game zero-leakage deterministic splitting, and compressed sharded output (`.jsonl.gz`). `research/nn/dataset.py` loads shards directly from `dataset_manifest.json`. `research/nn/train.py` accepts `--manifest` and `--train-shards`, removing hardcoded CLI training fixtures.
2. **Move / Action Encoding (RESOLVED)**: Canonical Vocabulary Version 2.0.0 (4,240 actions) maps standard moves (including Queen promotions) to indices $0 \dots 4095$, and White/Black underpromotions ($N, B, R$) to distinct slots $4096 \dots 4239$.
3. **Format & Checksum Discrepancy (Blocker)**: ADR_009 specifies an integrity checksum (CRC32 or SHA-256) in `.rks` files. Neither `tools/export_model.py` nor `engine/src/neural_evaluator.cpp` writes, checks, or defines any checksum field.
4. **PyTorch BatchNorm vs C++ Forward Pass (Blocker)**: `PolicyValueNet` uses `nn.BatchNorm2d(channels)` on every residual block and head, but `NeuralEvaluator` in C++ has no BatchNorm layer. While `export_model.py` attempts fusion `fuse_conv_bn()`, residual addition occurs before the final ReLU, and running statistics during eval mode must be verified for numeric equivalence. Moreover, test coverage skipped the real model test (`model_test.rks` does not exist on disk).
5. **C++ Search & UCI Disconnection (Blocker)**: `rooksac::neural::NeuralEvaluator` is **completely disconnected** from UCI and the active search loop. UCI hardcodes classical evaluation: `eval::evaluateSideToMove(pos)`. No UCI options exist for `EvalMode` or `ModelPath`. `SearchOptions` contains no toggle or pointer for neural leaf evaluation or policy move ordering.
6. **Backend Health & Process Leakage (Blocker)**: Backend `GET /api/v1/health` performs `engine_ready = True` statically without spawning or querying the engine process. Backend `UciEngineProcess` sends `setoption name Hash value 64` but does not pass any model path or evaluation mode.
7. **Frontend Hardcoded Base URL (Blocker)**: `app/frontend/src/api/client.ts` hardcodes `API_BASE = "/api/v1"`. If the frontend is hosted on a separate domain/port from the FastAPI backend (e.g. S3, Vercel, separate container), requests fail unless routed through a local reverse proxy.

## 3. Immediate Blockers

1. **Missing Model Checksum in Exporter and Loader**: `.rks` format does not yet implement the ADR_009 checksum specification.
2. **PyTorch-to-C++ Model Parity & Test Artifact**: Need a genuine trained model exported to `.rks` with automated numeric tolerance test.
3. **Engine-Search Neural Disconnect**: C++ engine has no runtime switch or search hook to use neural evaluation or policy ordering in real play.
4. **False Health Status**: Backend reports healthy even if the engine executable is missing or failing.
